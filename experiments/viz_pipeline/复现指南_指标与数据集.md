### 1.3 图像读取规则（与 LAMF 论文一致）

使用 `image_read_cv2(path, mode='GRAY')`（在 `utils/img_read_save.py` 中）：

```python
def image_read_cv2(path, mode='GRAY'):
    img_BGR = cv2.imread(path).astype('float32')   # ← 返回 float32，值域 0-255
    img = np.round(cv2.cvtColor(img_BGR, cv2.COLOR_BGR2GRAY))  # 灰度，np.round 后仍 float32
    return img
```

关键点：
- 读入返回 **float32**（不是 uint8），值域 [0, 255]
- 网络输入前 `/255.0` 归一化到 [0,1]

## 2. 融合推理规范

### 2.1 输入

```python
ir = torch.FloatTensor(ir_raw[np.newaxis, np.newaxis, ...] / 255.0).cuda()   # [1,1,H,W]
vis = torch.FloatTensor(vis_raw[np.newaxis, np.newaxis, ...] / 255.0).cuda()
```

### 2.2 推理

按各方法自身的网络前向，输入 IR 和 VIS 单通道灰度图，输出融合图 `fused ∈ [0,1]`（sigmoid 输出或等效归一化）。

### 2.3 输出处理（**与 LAMF 评估管线完全一致，不可省略**）

```python
fused = (fused - fused.min()) / (fused.max() - fused.min() + 1e-8)   # min-max 归一化
fi_np = np.squeeze((fused * 255.0).cpu().numpy()).astype(np.uint8)   # → uint8 [0,255]
img_save(fi_np, img_name_without_ext, out_dir)                        # 保存 PNG
```

即：**融合输出必须 min-max 归一化 → ×255 → uint8 → 保存为 PNG 文件**。

## 3. 指标计算规范（**关键，口径必须逐位一致**）

### 3.1 铁律：指标必须基于"保存后读回"的图像计算

**禁止**直接用内存中的 uint8 数组计算指标。原因：`Evaluator.SF` 等指标在 uint8 输入下会发生**减法溢出环绕**（如 `10-200=-190` 在 uint8 下环绕为 66），导致 SF 值腰斩（实测 7.87 vs 13.30）。

正确流程：

```python
# 1) 融合 → min-max → uint8 → 保存 PNG（见 2.3）
# 2) 用 image_read_cv2 读回（返回 float32！）
fi = image_read_cv2(os.path.join(out_dir, img_name + ".png"), 'GRAY')   # float32
ir = image_read_cv2(os.path.join(ir_dir, img_name), 'GRAY')             # float32
vi = image_read_cv2(os.path.join(vi_dir, img_name), 'GRAY')             # float32

# 3) 用 Evaluator 计算指标（输入均为 float32）
```

### 3.2 指标清单（8 项，全部越高越好）

| 指标 | Evaluator 方法 | 含义 |
|------|------|------|
| EN | `Evaluator.EN(fi)` | 信息熵 |
| SD | `Evaluator.SD(fi)` | 标准差（对比度） |
| SF | `Evaluator.SF(fi)` | 空间频率 |
| MI | `Evaluator.MI(fi, ir, vi)` | 互信息（F 与 IR/VIS 之和） |
| SCD | `Evaluator.SCD(fi, ir, vi)` | 差异相关和 |
| VIF | `Evaluator.VIFF(fi, ir, vi)` | 视觉信息保真度 |
| Qabf | `Evaluator.Qabf(fi, ir, vi)` | 边缘保留度 |
| SSIM | `Evaluator.SSIM(fi, ir, vi)` | 结构相似度（内部已用 data_range=255） |

可选附加指标（LAMF 论文未报告，若方法有优势可加）：`Evaluator.AG(fi)`（平均梯度）、`Evaluator.CC(fi, ir, vi)`（相关系数）。

### 3.4 已知坑点

| 坑 | 现象 | 规避 |
|------|------|------|
| uint8 减法溢出 | SF 腰斩（7.87 vs 13.30） | 必须 float32 读回后计算 |
| VIF 计算慢 | 单图 1-5s | 正常，无需处理 |
| Qabf 的 exp 溢出警告 | `RuntimeWarning: overflow encountered in exp` | 正常现象，结果仍正确（溢出分支 Q→0，与 eval_all.py 行为一致） |
| SSIM 参数 | 必须 data_range=255 | Evaluator.SSIM 已内置，勿用默认 skimage 调用 |
| 混合扩展名 | RoadScene 是 .jpg | 动态匹配扩展名 |

## 4. 输出规范

### 4.1 CSV 输出（主交付物）

文件命名: `perimg_<方法名>.csv`（如 `perimg_seafusion.csv`）

列定义（顺序固定）：

```
Image_ID,Dataset,EN,SD,SF,MI,SCD,VIF,Qabf,SSIM
```

- `Image_ID`: 不含扩展名的文件名（如 `01`、`FLIR_06392`）
- `Dataset`: `TNO` / `RoadScene` / `M3FD` / `FMB`
- 数值保留 float 全精度即可（无需四舍五入）

示例（取自已验证的 perimg_cddfuse.csv）：

```csv
Image_ID,Dataset,EN,SD,SF,MI,SCD,VIF,Qabf,SSIM
01,TNO,6.7698,44.91,13.73,2.1855,1.7605,0.7682,0.5391,1.3406
02,TNO,7.1168,46.00,13.15,2.31,1.71,0.80,0.55,1.32
```

### 4.2 推理图像保存（用于可视化对比）

**必须保留**每张图的融合结果 PNG，后续用于论文定性对比图：

```
<输出根目录>/fused_images/<数据集名>/<Image_ID>.png
```

示例:
```
fused_images/TNO/01.png
fused_images/RoadScene/FLIR_06392.png
fused_images/M3FD/xxx.png
fused_images/FMB/xxx.png
```

这些图需满足：
- uint8，灰度，min-max 归一化后 ×255 保存
- 文件名与源图（去扩展名）一致

### 4.3 附加交付

- 每数据集平均值（可选，便于快速核对）：`avg_<方法名>.txt` 或直接写在 CSV 末尾注释
- 推理时间（可选）：单图平均 ms

## 6. 完整流程速查（伪代码）

```
for dataset in [TNO, RoadScene, M3FD, FMB]:
    for img_name in sorted(ir 目录文件列表):           # 与 vi 目录一一对应
        ir = read_float32(dataset/ir/img_name)        # image_read_cv2 GRAY
        vi = read_float32(dataset/vi/img_name)
        fused = model_forward(ir/255, vi/255)         # 各方法网络
        fused = minmax_norm(fused)                    # (x-min)/(max-min+1e-8)
        fi_uint8 = (fused * 255).astype(uint8)
        save_png(fi_uint8, fused_images/dataset/img_name)
        fi = read_float32(saved_png)                  # ← 读回 float32！
        row = [img_id, dataset, EN(fi), SD(fi), SF(fi), MI(fi,ir,vi),
               SCD(fi,ir,vi), VIF(fi,ir,vi), Qabf(fi,ir,vi), SSIM(fi,ir,vi)]
        append row to perimg_<method>.csv
```
